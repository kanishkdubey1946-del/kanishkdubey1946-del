## 🌱 Featured Project — AgroBot

> **Smart Irrigation System using IoT + Gen AI**

AgroBot is an IoT-based agricultural automation system that:
- 📡 Monitors **soil moisture & temperature** in real-time using sensors
- 💧 **Automatically controls irrigation** based on sensor data
- 🤖 Integrating **Generative AI** for smart farming recommendations
- 🌾 Goal: Make smart agriculture accessible for small-scale farmers in India

🔗 [View AgroBot on GitHub](https://github.com/kanishkdubey1946-del/agrobot-smart-irrigation-system)
